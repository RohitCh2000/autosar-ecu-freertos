# AUTOSAR ECU on FreeRTOS
AUTOSAR Classic-style ECU software example on FreeRTOS for ARM Cortex platforms: software components (SWC) and RTE concepts, BSW services, CAN/CAN-FD message processing, and UDS diagnostics (session control, DTC retrieval, ECU reset, routine control).

Personal project based on professional automotive embedded experience (no employer code).

## Features
- FreeRTOS task scheduling, interrupts and synchronization for deterministic execution
- CAN / CAN-FD signal handling
- UDS diagnostic services (ISO 14229 concepts)
- SIL/HIL validation notes with CANoe/CANalyzer-style scenarios
- MISRA C and ISO 26262-oriented practices

## Tech
Embedded C/C++, FreeRTOS, ARM Cortex-M, AUTOSAR Classic, CAN, CAN-FD, UDS
